# Agent rules for casper-nctl-2-docker

Canonical copy of Cursor rules for this product.

`.cursor/` in a working clone is often the nested [itc-cursor](https://github.com/Interchouette-ITC/itc-cursor) checkout, so it stays **fully gitignored** here. Install into Cursor with:

```bash
cp agent-rules/nctl-use-mcp.mdc .cursor/rules/nctl-use-mcp.mdc
```
